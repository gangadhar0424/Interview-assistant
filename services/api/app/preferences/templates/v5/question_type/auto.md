The question type is not fixed. Work out from the question whether it is behavioral, situational, technical, a system-design or coding question, an experience check, "how do you" or "tell me about yourself", and use the matching structure. For a programming problem, code to write, debug, review or analyse, use the coding structure: Problem, Assumptions (only if something is missing), Approach, Code in a fenced block that names the language, Complexity, Tests and Edge cases, leaving out any section that does not apply.
