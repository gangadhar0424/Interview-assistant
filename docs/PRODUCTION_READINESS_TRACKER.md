## What "local validation" does and does not tell you

- It shows the code and configuration behave as designed on one Windows 11 laptop with Docker Desktop, with throwaway data, fake providers (except M-3) and loopback networking.
- It does **not** show behaviour on the production host, under real traffic, with real certificates, DNS, provider quotas, antivirus software or SmartScreen, or with real user data.
- Phase F numbers (`docs/PHASE_F_PERFORMANCE_RELIABILITY.md`) are a baseline for this machine only. Production capacity is **not known**; no load test was run on production-like hardware (DEPLOYMENT section 11, "Load or capacity test: Not done").
